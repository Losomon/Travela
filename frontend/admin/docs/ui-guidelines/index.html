UI Guidelines

Consistent, accessible, and delightful user interfaces for Travela.

Layout Principles

Grid System

12-column responsive grid with 20px gutters. Use Bootstrap's container for consistent margins.

Mobile-First

Design for mobile first, then enhance for tablet and desktop breakpoints.

Visual Hierarchy

Use size, weight, and spacing to guide users through content.

Do's & Don'ts

Navigation

DO:

Keep navigation sticky on scroll for easy access. Use descriptive labels for menu items.

DON'T:

Overcrowd the navbar with more than 7 items. Use dropdowns for secondary links.

Buttons

DO:

Use primary buttons for main actions (Book Now, Explore). Keep button text action-oriented.

DON'T:

Use too many different button styles on one page. Avoid generic "Click Here" text.

Forms

DO:

Use clear labels above inputs. Show validation errors inline.

DON'T:

Use placeholder text as the only label. Make forms longer than necessary.

Accessibility Standards

Travela is committed to WCAG 2.1 AA compliance.

  • Semantic HTML5 elements
  • ARIA labels on interactive elements
  • Keyboard navigation support
  • Sufficient color contrast (4.5:1)
  • Alt text for all images
  • Focus indicators visible
